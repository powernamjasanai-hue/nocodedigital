이 워크시트는 **Chapter 2: 당신 안에 숨겨진 수익 씨앗**에서 사용합니다.

10분 안에 당신의 강점을 발견하고, 수익화 아이템으로 전환하는 프레임워크입니다.

## 🎯 질문 3가지

### 질문 1: 내가 10번 이상 해본 것은?

**설명**: 경험 = 돈입니다. 반복해서 해본 것은 당신의 전문성입니다.

```
예시:
- 엑셀로 데이터 분석 (회사 업무)
- 육아 (3년차)
- 다이어트 (5kg 감량 성공)
- 여행 계획 세우기 (연 4회)
```

**나의 답변**:

1. _______________________________________________
2. _______________________________________________
3. _______________________________________________
4. _______________________________________________
5. _______________________________________________

---

### 질문 2: 친구가 나한테 조언 구하는 것은?

**설명**: 남들이 당신에게 물어본다 = 당신의 강점입니다.

```
예시:
- "너 PPT 잘 만들잖아, 좀 봐줘"
- "맛집 추천해줘"
- "운동 어떻게 시작했어?"
- "이직 준비 어떻게 했어?"
```

---

### 질문 3: 내가 돈/시간 많이 쓴 분야는?

**설명**: 당신이 투자한 분야 = 당신이 관심 있고 잘 아는 분야입니다.

```
예시:
- 영어 공부 (학원, 책, 강의 100만 원+)
- 카페 (주 5회, 월 20만 원)
- 피부 관리 (화장품, 관리실 월 15만 원)
- 주식 투자 (3년간 학습 및 실전)
```
