## 📐 페이지 조정 계획

### 만약 55페이지 → 50페이지로 축소 필요 시

#### 우선순위별 축소 방안

**1. 부록 축소 (5p → 3p)**: -2페이지
- 워크시트는 별도 파일로 제공
- 도구 리스트 간소화

**2. Chapter 5 축소 (8p → 6p)**: -2페이지
- 플랫폼 TOP 5 → TOP 3
- 각 플랫폼 설명 간소화

**3. Chapter 1 축소 (8p → 7p)**: -1페이지
- 두려움 부분 통합

**합계**: -5페이지 = 50페이지 정확히 맞춤
