# 시장 리서치 데이터

## 1. 노션 랜딩페이지 트렌드 (2024-2025)

### 주요 발견
- 노션 랜딩페이지는 **코딩 없이 쉽게** 만들 수 있어 인기
- 우피(Oopy), 슬래시페이지 같은 노션→웹 변환 툴 활발
- 포트폴리오, 랜딩페이지, 이벤트 페이지로 활용
- 템플릿 기반 제작이 주류

### 인사이트
→ 독자들은 "쉽고 빠르게" 만드는 방법을 찾고 있음

## 2. 디지털 제품 판매 시장

### 주요 발견
- 디지털 제품 판매는 1인 창업의 대표 아이템
- 한 번 만들면 무한 판매 가능 (재고 없음)
- 적은 초기 자본으로 시작 가능
- **잘 팔리는 주제: "00 노하우" 실용서**
- 주요 상품: 전자책, 템플릿, 강의, 굿노트 스티커, 플래너

### 인사이트
→ 독자들은 "적은 비용으로 빠르게 시작"하고 싶어 함

## 3. 플랫폼 수수료 현실

### 크몽 수수료
- 50만원 이하: **20%**
- 50-200만원: **12%**
- 200만원 초과: **6%**
- + 부가세 + 결제망 수수료

### 탈잉 수수료
- 원데이 클래스: **15%**
- 다회차 클래스: **14%**
- 전자책/녹화영상: **20%**
- + 부가세 + 소득세 3.3%

### 인사이트
→ **실제로 받는 돈은 70-80% 수준**
→ Latpeed 1.6%가 얼마나 혁신적인지 명확함

## 4. 1인 크리에이터 시장

### 통계
- 2019년: 4,875명 → 2020년: **33,065명** (7배 증가)
- 총 수입: **4,521억원** (2020년)
- 전 세계 크리에이터: **3억 3백만 명**
- 최근 2년간 **1억 6500만 명** 신규 진입

### 수익 모델
- 광고, 브랜드 콘텐츠, 구독, 제품 판매, 유료 디지털 상품

### 인사이트
→ 경쟁은 치열하지만 시장은 계속 성장 중
→ 블로그/인스타 있는 사람들이 수익화 방법을 찾고 있음
