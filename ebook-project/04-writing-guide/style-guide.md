# 전자책 글쓰기 스타일 가이드 (확정)

## 📌 핵심 원칙

**"초등학생도 이해할 수 있는 언어로, 친근하게, 실행 중심으로"**

---

## 1. 문체

### 존칭
- **~요/~입니다 혼합**
- 친근한 구어체 기반
- 초등학생도 이해할 수 있는 언어

**예시:**
```
좋은 예:
크몽 수수료는 20%예요. 100만원 팔면 20만원을 내야 합니다.
실제로 제가 첫 달에 판매했을 때 정산 금액을 보고 놀랐어요.

나쁜 예:
크몽의 수수료 구조는 판매액의 20%로 책정되어 있으며, 이는...
```

### 관점
- **1인칭 중심** (저, 제가)
- "당신", "여러분" 최소화 또는 생략
- 설명하는 느낌

**예시:**
```
좋은 예:
전자책을 만들었다면 이제 판매할 곳을 찾아야 해요.

나쁜 예:
당신이 전자책을 만들었다면 당신은 이제 판매할 곳을 찾아야 합니다.
```

## 2. 태도

### 상황별 톤
1. **경험 공유형** (제 경험/사례 설명할 때)
   - "저도 처음엔 막막했어요"
   - "실제로 해보니..."
   - 진솔하고 공감 가능하게

2. **전문가형** (방법 설명할 때)
   - "이렇게 하면 됩니다"
   - "방법은 명확해요"
   - 자신감 있고 직접적으로
   - **단, 문체는 동일하게 유지**

**예시:**
```
경험 공유형:
저도 처음엔 노션으로 팔릴까 의심했어요.
그런데 막상 해보니 아임웹보다 전환율이 더 높더라고요.

전문가형:
헤드카피 작성은 간단해요.
타겟의 문제를 질문형으로 던지고, 해결책을 제시하면 됩니다.
```

## 3. 이모지

**절대 사용 금지**

대체 표현:
- ✅ → 또는 (필요 시)
- ❌ → X 또는 (불필요)
- 🔥 → **굵게** 또는 생략
- 😊 → 삭제

## 4. 문단 구조

### 2가지 기본 틀

**틀 1: 이해형 (개념/배경 설명)**
```
문단 1: 무엇인가 + 왜 중요한가 (150-200자)
문단 2: 구체적 설명 + 데이터/예시 (200-250자)
문단 3: 결론/정리 (50-100자, 선택)
```

**틀 2: 실용형 (방법/실행 설명)**
```
문단 1: 목표 + 개요 (100-150자)
문단 2: 실행 방법 (200-300자)
문단 3: 주의사항/팁 (50-100자, 선택)
```

**유연하게 적용:** 내용에 따라 조정 가능

## 5. 소목차별 글 구조

### 기본 구성
```
## 소목차 제목 (명사형/질문형/행동형)

문단 1
...

문단 2
...

(필요시) 표/리스트
...

문단 3
...
```

### 원칙
- **텍스트 중심** 작성
- 표/리스트는 **정말 필요할 때만** 사용
- 헤딩(##) 유지
- 박스/인용구 사용 금지

---

## 6. 강조 표현

### 허용되는 강조
1. **굵게** (중요 단어/문장)
2. 기호:
   - → (화살표, 흐름/결과)
   - • (불렛 포인트)
   - ─ (구분선)

### 금지 사항
- "" 쌍따옴표 사용 금지
- '' 따옴표만 사용
- 박스 사용 금지
- 이모지 금지

**예시:**
```
좋은 예:
크몽 수수료는 '진짜 비용'입니다.
플랫폼 의존도가 높아질수록 → 자유도는 낮아집니다.

나쁜 예:
크몽 수수료는 "진짜 비용"입니다.
┌─────────────┐
│ 중요 포인트 │
└─────────────┘
```

## 7. 예시 작성법

**인라인 방식만 사용**

박스/구분 없이 자연스럽게 흐름 속에 삽입

**예시:**
```
좋은 예:
예를 들어 민지님은 첫 달에 12개를 팔아서 348,000원을 벌었어요.
Latpeed 수수료는 5,568원이었고, 만약 크몽이었다면 69,600원을 냈을 거예요.

나쁜 예:
[사례]
민지님: 12개 판매, 348,000원
```

## 8. 데이터 표현

**편한 대로 사용** (일관성만 유지)

권장:
- 큰 숫자: 100만원, 1,200만원
- 작은 숫자: 15,000원, 1,000원
- 비율: 20%, 1.6%
- 배수: 3배, 10배

**예시:**
```
크몽 수수료 20%
연 1,200만원 판매 시 240만원 손실
Latpeed는 1.6%라서 19만원만 내면 돼요.
```

## 9. 독자 호칭

### 원칙
- **"당신" 절대 금지**
- "여러분" 또는 **생략** (생략 우선)

**예시:**
```
좋은 예:
전자책을 만들었다면 이제 판매 채널을 정해야 해요.
(생략)

여러분도 오늘부터 시작할 수 있어요.
(여러분 - 필요시)

나쁜 예:
당신이 전자책을 만들었다면 당신은...
```

## 10. 문장 길이

### 기본 원칙
- **15-25자** 기본
- **변동성 있게** (짧은 문장 + 긴 문장 섞기)

**예시:**
```
좋은 예:
크몽 수수료는 20%예요. (10자)
100만원을 팔면 20만원을 수수료로 내야 합니다. (25자)
1년이면? (5자)
무려 240만원이 플랫폼으로 들어가는 거예요. (23자)

나쁜 예:
크몽의 판매 수수료 정책에 따르면 판매액의 20%를 수수료로 책정하고 있으며 이는 100만원 판매 시 20만원을 의미합니다. (60자 - 너무 김)
```

---

## 11. 리스트 표현

### 번호 리스트
- 순서가 있는 내용: **1. 2. 3.**
- 순서 없는 내용: **• (불렛)**

**예시:**
```
준비물:
1. 노션 계정
2. 판매할 PDF
3. ChatGPT 계정

장점:
• 무료
• 쉬움
• 빠름
```

## 12. 소목차 제목

### 형식
- **명사형** (기본)

```
행동형: 플랫폼 수수료 계산하기
```

## 13. 표 사용

### 사용 시점
- 비교가 필요할 때만
- 데이터가 3개 이상일 때
- 텍스트로 쓰면 복잡할 때

### 구조
- 간결하게 (3-4열 이내)
- 헤더 명확하게
- 수치 중심

**예시:**
```
| 플랫폼 | 수수료 | 연 1,200만원 시 |
|--------|--------|-----------------|
| 크몽 | 20% | 240만원 손실 |
| Latpeed | 1.6% | 19만원 |
```

1. **친근하고 쉽게** (초등학생도 이해)
