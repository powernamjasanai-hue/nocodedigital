<a name="hero"></a>
## Hero 섹션 (가격 & 혜택)

### 사용 시점
- 랜딩페이지 최상단 (첫인상)
- 가격과 할인율을 강조하고 싶을 때
- 즉시 구매 유도가 필요할 때

### 기본 모듈

```
┌─────────────────────────────────────────┐
│ Callout (배경색: Light gray)           │
│                                         │
│  [Image] (Full width)                   │
│  [전자책 커버 이미지 1200x630px]       │
│                                         │
│  # 노션으로 1시간 만에                 │
│  # 디지털 제품 판매 시스템 만들기      │
│  (Heading 1, Center align)              │
│                                         │
│  코딩 없이 오늘 2-3시간이면 판매 시작  │
│  (Text Large, Center align)             │
│                                         │
│  ───────────────────────────            │
│                                         │
│  [2열 레이아웃]                         │
│  정가: ₩79,000                          │
│  (Text Large, Strikethrough)            │
│                                         │
│  할인가: ₩49,000 (38% OFF)              │
│  (Heading 1, Red color)                 │
│                                         │
│  [Button] 지금 구매하기                 │
│  (Button Primary, Center)               │
│  → Latpeed 링크 연결                    │
└─────────────────────────────────────────┘
```

### 작성 예시

```
[복사하여 사용하세요]

Callout (Light gray)
───────────────────────────────────

[Image] 여기에 전자책 커버 이미지를 드래그하세요

# 노션으로 1시간 만에 디지털 제품 판매 시스템 만들기

코딩 없이 오늘 2-3시간이면 판매 시작

─────────────────────────────────────

정가: ₩79,000 (취소선)  |  할인가: ₩49,000 (38% OFF) ← 빨간색 강조

[Button] 지금 구매하기
```

### 작성 팁 (Toggle)

> **커버 이미지**
> - 크기: 1200x630px 권장
> - 도구: 나노바나나 활용
> - 내용: 제목 + 핵심 베네핏 1가지
>
> **제목**
> - 15자 이내로 간결하게
> - 핵심 키워드 포함 (예: "노션", "1시간", "판매 시스템")
>
> **가격**
> - 할인율은 30% 이상이면 심리적 효과 큼
> - 원가를 취소선 처리하여 할인감 강조

## P (Problem) - 문제 제기

### 사용 시점
- 타겟 고객의 문제를 구체적으로 언급할 때
- 공감대를 형성하고 주의를 끌 때
- 여러 문제를 한 번에 보여주고 싶을 때

### 레이아웃 A: 나열형 (기본)

```
┌─────────────────────────────────────────┐
│ Callout (배경색: Light red)            │
│                                         │
│  # 이런 고민 있으시죠?                  │
│  (Heading 1)                            │
│                                         │
│  [Image] (Center align)                 │
│  [문제 상황 이미지]                     │
│                                         │
│  전자책 PDF는 완성했는데,               │
│  크몽 수수료 20%가 아까워서             │
│  망설이고 계신가요?                     │
│  (Text Large)                           │
│                                         │
│  ┌───────────────────────────┐         │
│  │ Callout                   │         │
│  │ 15만원 팔면 3만원이       │         │
│  │ 수수료로 나간다           │         │
│  └───────────────────────────┘         │
│                                         │
│  ┌───────────────────────────┐         │
│  │ Callout                   │         │
│  │ 고객 이메일은 플랫폼이    │         │
│  │ 가져가서 재구매 유도 불가 │         │
│  └───────────────────────────┘         │
│                                         │
│  ┌───────────────────────────┐         │
│  │ Callout                   │         │
│  │ 홈페이지 외주는 2주 걸리고│         │
│  │ 100만원 든다              │         │
│  └───────────────────────────┘         │
└─────────────────────────────────────────┘
```

### 작성 예시 (나열형)

```
[복사하여 사용하세요]

Callout (Light red)
───────────────────────────────────

# 이런 고민 있으시죠?

[Image] 문제 상황을 나타내는 이미지

전자책 PDF는 완성했는데, 크몽 수수료 20%가 아까워서 망설이고 계신가요?

[Callout]
15만원짜리 제품을 팔 때마다 3만원을 수수료로 내야 합니다. 10개 팔면 30만원이 날아가요.

[Callout]
게다가 고객 이메일은 플랫폼이 가져가서, 재구매를 유도하거나 후속 제품을 알릴 방법이 없습니다.

[Callout]
홈페이지 외주를 맡기자니 2주는 걸리고 100만원 이상 듭니다. 그 동안 기회비용만 손해예요.
```

```
│   2주 대기      │   만에 완성      │
└─────────────────┴─────────────────┘
```

### 작성 팁 (Toggle)

> **문제 선정**
> - 타겟 고객이 가장 아파하는 3-5개 선정
> - 구체적 숫자 포함 (예: "20% 수수료", "100만원")
> - 감정 단어 사용 (예: "아깝다", "답답하다", "막막하다")
>
> **구조 선택**
> - 나열형: 여러 문제를 강조할 때
> - 비교형: Before/After 대비를 명확히 보여줄 때
>
> **심리학적 근거**
> 연구에 따르면 단일 문제보다 여러 문제가 나열될 때 '이 사람이 나를 이해한다'고 느끼는 확률이 3배 높습니다.

<a name="agitate"></a>
## A (Agitate) - 공감 유발

### 사용 시점
- 문제를 제기한 후 감정적 공감을 끌어낼 때
- 본인의 경험을 공유하여 신뢰를 쌓을 때
- 문제의 심각성을 더 강조하고 싶을 때

### 기본 모듈

```
┌─────────────────────────────────────────┐
│ Callout (배경색: Light yellow)         │
│                                         │
│  # 저도 그랬어요                        │
│  (Heading 1)                            │
│                                         │
│  "처음 크몽에서 15만원 상품을 팔았을   │
│  때, 수수료로 3만원이 나가는 걸        │
│  보고 충격받았어요."                    │
│  (Quote 블록 또는 Text Large)           │
│                                         │
│  맞아요. 저도 그랬어요.                 │
│  100만원 매출에서 20만원이 수수료로    │
│  날아가는 걸 보면서 '내가 뭐하는       │
│  건가' 싶더라고요.                      │
│  (Text)                                 │
│                                         │
│  게다가 고객 이메일도 플랫폼이         │
│  가져가니까, 내 고객인데도 다시        │
│  연락할 방법이 없더라고요.              │
│  (Text)                                 │
│                                         │
│  [Image - 선택사항]                     │
│  [본인의 경험 스크린샷 또는 공감 이미지│
└─────────────────────────────────────────┘
```

### 작성 예시

```
[복사하여 사용하세요]

Callout (Light yellow)
───────────────────────────────────

# 저도 그랬어요

"처음 크몽에서 15만원짜리 상세페이지 시안을 팔았을 때, 수수료로 3만원이 나가는 걸 보고 충격받았어요."

맞아요. 저도 그랬어요. 100만원 매출에서 20만원이 수수료로 날아가는 걸 보면서 '내가 뭐하는 건가' 싶더라고요.

게다가 고객 이메일도 플랫폼이 가져가니까, 내 고객인데도 다시 연락할 방법이 없더라고요. 리뷰 1개 받으려면 플랫폼 눈치를 봐야 하고, 가격도 내 마음대로 못 올리고...

그래서 생각했어요. "내가 직접 판매 시스템을 만들면 안 되나?"

[Image - 선택: 본인의 크몽/탈잉 판매 수수료 스크린샷]
```

### 작성 팁 (Toggle)

> **효과적인 공감 문구**
> - 본인의 **실제 경험** 사용 (가장 강력함)
> - **구체적 금액**이나 숫자 포함 (예: "100만원 중 20만원")
> - **감정 단어** 사용 (예: "답답하다", "속상하다", "억울하다")
> - **3-4문장**으로 짧게 (너무 길면 집중도 하락)
>
> **Quote vs Text**
> - Quote 블록: 타인의 후기나 본인의 핵심 문장 강조
> - Text 블록: 일반적인 서술
>
> **심리학적 근거**
> 심리학의 '자기 참조 효과(Self-Reference Effect)'에 따르면, 타인의 경험담이 자신의 것과 유사하다고 느낄 때 신뢰도가 89% 상승합니다.

## T (Trust) - 가치 입증

### 사용 시점
- 독자의 의심을 해소하고 신뢰를 구축할 때
- 구체적 데이터나 실적으로 증명할 때
- 저자의 전문성을 보여줄 때

### 레이아웃 A: 비교 데이터 + 저자 소개

```
┌─────────────────────────────────────────┐
│ Callout (배경색: Light blue)           │
│                                         │
│  # 실제 데이터를 보여드릴게요           │
│  (Heading 1)                            │
│                                         │
│  [Image 또는 Table]                     │
│  [비교 데이터 시각화]                   │
│                                         │
│  크몽에서 월 200만원 팔면 40만원을     │
│  수수료로 냅니다. **1년이면 480만원**  │
│  이에요.                                │
│  (Text Large, Bold numbers)             │
│                                         │
│  ───────────────────────────            │
│                                         │
│  ## 이 시스템을 만든 사람               │
│  (Heading 2)                            │
│                                         │
│  [2열 레이아웃]                         │
│                                         │
│  [왼쪽] Image                           │
│  [저자 프로필 또는 실적 스크린샷]      │
│                                         │
│  [오른쪽] Text                          │
│  · 5년간 상세페이지 디자이너           │
│  · 누적 매출 1.4억원 달성               │
│  · 200개 이상의 랜딩페이지 제작         │
│  · 2023년부터 노션 랜딩페이지로        │
│    수수료 0원 시스템 구축               │
└─────────────────────────────────────────┘
```

### 작성 예시 (비교 데이터)

```

|------|----------|--------------|------|
| 수수료 | 20% | 1.6% | **18.4%↓** |
| 15만원 판매 시 | -3만원 | -2,400원 | +27,600원 |
| 월 200만원 시 | -40만원 | -32,000원 | **+368,000원** |
| 연간 (×12개월) | -480만원 | -384,000원 | **+4,416,000원** |

크몽에서 월 200만원 팔면 40만원을 수수료로 냅니다. **1년이면 480만원**이에요.

같은 제품을 노션+Latpeed로 팔면 1년에 38만원만 수수료로 냅니다. **442만원 절감**입니다.

───────────────────────────────────

## 이 시스템을 만든 사람

[2열 레이아웃]

[Image] 저자 프로필 또는 실적 스크린샷

**김OO**
· 5년간 상세페이지 디자이너로 활동
· 누적 매출 1.4억원 달성
· 200개 이상의 랜딩페이지 제작 경험
· 2023년부터 노션 랜딩페이지로 수수료 0원 시스템 구축
· 현재 월평균 300만원 매출 유지 중
```

>
> **숫자 강조 방법**
> - Bold 처리로 핵심 숫자 강조
> - 비교 수치는 반드시 함께 제시 (Before/After)
> - 연간 금액으로 환산하면 임팩트 증가
>
> **저자 소개 작성 팁**
> - 이론보다 **실전 경험** 위주
> - 구체적 숫자 포함 (예: "누적 매출 1.4억원")
> - 현재 진행형 실적 언급 (예: "현재 월평균 300만원")
>
> **심리학적 근거**
> Nielsen Norman Group 연구에 따르면, 비교 데이터는 단일 주장보다 설득력이 4.3배 높습니다.

## 최종 활용 팁

### 빠른 시작 가이드

1. **Hero 섹션부터 시작**
   - 가격과 제목만 먼저 결정
   - 나머지는 나중에 수정 가능

2. **PATSBC 순서대로 작성**
   - P (문제) → A (공감) → T (신뢰) → S (솔루션) → B (베네핏) → C (행동유도)
   - 순서를 지키면 논리적 흐름이 자연스러움

3. **처음엔 80% 완성도로**
   - 완벽하게 작성하려 하지 말고 일단 공개
   - 고객 피드백 받아서 개선

4. **재사용 블록 적극 활용**
   - 베네핏이 5개 필요하면 "베네핏 블록" 5번 복사
   - 프로세스가 5단계면 "3열 레이아웃"을 2개로 나눠서 사용
