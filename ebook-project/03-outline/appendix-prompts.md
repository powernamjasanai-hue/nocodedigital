## 프롬프트 1: 리서치를 돕는 프롬프트 (1.5페이지)

### 사용 시점
- 전자책 기획 초기
- 시장 조사 필요할 때
- 경쟁사 분석할 때

### 프롬프트 전문
```
당신은 시장 조사 전문가입니다.

【분석 대상】
- 주제: [내 전자책 주제, 예: 노션 랜딩페이지 제작]
- 타겟 시장: [예: 1인 크리에이터, 디지털 제품 판매자]

【요청 1: 시장 트렌드 분석】
이 주제와 관련된 최근 트렌드 5가지를 알려주세요.
- 2024-2025년 키워드
- 검색량 증가 추이
- 주요 변화

【요청 2: 경쟁사 분석】
유사한 제품/서비스를 판매하는 경쟁자를 분석해주세요.
- 주요 플레이어 5개
- 가격대
- 차별화 포인트
- 리뷰 분석 (장단점)

【요청 3: 기회 영역】
경쟁사가 놓치고 있는 부분은 무엇인가요?
- 고객 불만 사항
- 미충족 니즈
- 차별화 가능한 지점

【형식】
- 표로 정리
- 핵심만 간결하게
- 출처 표시 (가능하면)
```

### 활용 예시
- 입력 예시
- 출력 예시
- 어떻게 전자책에 반영하는지

## 프롬프트 2: 타겟 분석 프롬프트 (1.5페이지)

### 사용 시점
- 랜딩페이지 카피 작성 전
- 타겟이 모호할 때
- 페르소나 구체화 필요할 때

### 프롬프트 전문
```
당신은 마케팅 심리 분석 전문가입니다.

【제품 정보】
- 제품명: [내 전자책 제목]
- 주제: [간단 설명]
- 가격: [예상 가격대]
- 제공 가치: [해결하는 문제]

【요청 1: 페르소나 3종 생성】
이 제품을 구매할 가능성이 높은 타겟을 3가지 페르소나로 나눠주세요.

각 페르소나마다:
1. 이름 & 별명 (예: "전자책 완성했지만 판매 막막한 민지")
2. 기본 정보
   - 나이/성별
   - 직업/소득 수준
   - 디지털 활용 수준
3. 현재 상황
   - 어떤 단계에 있는지
   - 가진 것 / 부족한 것
4. 핵심 고민 3가지 (구체적으로)
5. 구매 동기 (왜 이 제품을 사려고 하는가)
6. 구매 장벽 (망설이는 이유)
7. 가격 지불 의향 (얼마까지 낼 수 있는가)

【요청 2: Pain Point 구체화】
페르소나 1의 고민을 더 깊이 파고들어주세요.
- 밤에 잠 못 이루게 만드는 고민
- "이것만 해결되면 돈 아깝지 않다" 싶은 것
- 지금 당장 필요한 것 vs 나중에 필요한 것

【요청 3: 구매 결정 요인】
이 페르소나가 "지금 사야겠다"고 결심하는 순간은 언제인가요?
- 트리거 상황 3가지
- 감정 상태
- 최종 한 마디 (구매 버튼 누르기 직전 생각)

【형식】
- 표로 정리
- 감정적 언어 사용
- 구체적인 상황 묘사
```

### 활용 예시
- 실제 대화 스크린샷
- 페르소나 출력 결과
- 랜딩페이지 카피에 적용하는 법

## 프롬프트 3: 스레드 글쓰기 프롬프트 (1.5페이지)

### 사용 시점
- 스레드 마케팅 시작할 때
- 매일 포스팅 소재 필요할 때
- 바이럴 콘텐츠 만들고 싶을 때

### 프롬프트 전문
```
당신은 바이럴 콘텐츠 전문 작가입니다.

【제품 정보】
- 제품명: [내 전자책 제목]
- 타겟: [Section 2-1에서 정의한 타겟]
- 핵심 베네핏: [3가지]
- 차별점: [경쟁사와 다른 점]

【요청 1: 7일 포스팅 플랜】
스레드(Threads)에 올릴 콘텐츠를 7일치 기획해주세요.

각 날짜별:
- Day 1: 문제 제기 (타겟의 고민 공감)
- Day 2: 내 경험 (실패담 → 깨달음)
- Day 3: 솔루션 힌트 (비밀 1개 공개)
- Day 4: 증거 (데이터, 스크린샷)
- Day 5: 후기/사례 (실제 사용자 이야기)
- Day 6: FAQ (자주 묻는 질문)
- Day 7: 긴급 오퍼 (할인, 보너스)

【요청 2: Day 1 포스팅 작성】
첫 번째 포스팅을 구체적으로 작성해주세요.

형식:
- 첫 줄: 후킹 (멈춰서 읽게 만들기)
- 본문: 3-5문장 (공감 → 문제 → 힌트)
- 마지막: 질문 (댓글 유도)
- 해시태그: 5-7개
- 이모지: 적절히 사용

톤: 친근하고 진솔하게 (~요 체)
길이: 150-200자 (스레드 최적 길이)

【요청 3: 바이럴 후킹 문장 10개】
스크롤 멈추게 만드는 첫 문장 10개를 만들어주세요.

형식:
- 질문형 / 충격형 / 공감형 섞어서
- 타겟의 언어로
- 호기심 자극

예시:
"전자책 10권 만들었는데 판매 0원인 이유.txt"
"플랫폼 수수료 20%... 여러분은 이거 아깝지 않나요?"
```

### 활용 예시
- ChatGPT 대화 스크린샷
- 7일 플랜 결과
- 실제 스레드 포스팅 예시 3개

## 프롬프트 4: PATSBC 카피라이팅 프롬프트 (0.5페이지)

### 사용 시점
- Chapter 2 Section 2-3에서 사용
- 랜딩페이지 카피 작성할 때

### 프롬프트 전문
```
당신은 전문 카피라이터입니다.

【제품 정보】
- 제품명: [내 전자책 제목]
- 타겟: [Section 2-1에서 정의한 타겟]
- 핵심 Pain Point: [타겟의 가장 큰 고민]
- 베네핏: [3가지]

【요청】
PATSBC 구조로 랜딩페이지 카피를 작성해주세요.

P (Problem): 타겟의 문제를 질문형으로 2-3문장
A (Agitate): 문제의 고통을 공감하며 3-4문장
T (Testimony): 데이터/통계로 근거 제시 2-3문장
S (Solution): 이 전자책이 어떻게 해결하는지 3-4문장
B (Benefit): 구체적 베네핏 3가지 (각 1-2문장)
C (CTA): 구매 유도 2문장 + 긴급성 1문장

톤: 친근하고 구체적으로 (~요/~입니다 혼합)
```

*(전체 프롬프트는 Chapter 2 Section 2-3에 있음)*

## 💡 프롬프트 사용 팁

### 더 좋은 답변 받는 법 (800자)
1. **구체적으로 입력하기**
   - ❌ "전자책 주제: 마케팅"
   - ✅ "전자책 주제: 노션으로 만드는 1시간 랜딩페이지"

2. **맥락 제공하기**
   - "나는 1인 크리에이터고, 1.4억 매출 경험이 있어"
   - "타겟은 전자책 만들었지만 판매 방법 모르는 사람"

3. **예시 요구하기**
   - "예시 3개를 구체적으로 보여줘"
   - "표로 정리해줘"

4. **반복 개선하기**
   - 첫 답변에 만족 안 되면 "더 구체적으로" 요청
   - "이 부분만 다시 작성해줘"

## 간단 FAQ 10개 (0.5페이지)

**Q1. ChatGPT 무료 버전으로 가능한가요?**
A. 네, 가능합니다. 유료(GPT-4)면 더 좋지만 필수는 아닙니다.

**Q2. 프롬프트 결과가 마음에 안 들면?**
A. "더 구체적으로", "다른 버전 3개" 요청하세요.

**Q3. 영어 답변이 나오면?**
A. 프롬프트에 "한국어로 답변해주세요" 추가.

**Q4. 이 프롬프트를 수정해도 되나요?**
A. 당연합니다. 내 상황에 맞게 자유롭게 수정하세요.

**Q5. 다른 AI (Claude, Gemini)로도 가능한가요?**
A. 네, 모든 AI에서 작동합니다.

**Q6. 프롬프트가 너무 긴데 줄여도 되나요?**
A. 핵심만 남기고 줄여도 되지만, 구체적일수록 좋은 답변이 나옵니다.

**Q7. 실제 데이터를 어떻게 입력하나요?**
A. [대괄호] 부분을 내 정보로 바꾸세요.

**Q8. 답변을 그대로 써도 되나요?**
A. 80% 쓰고 20%는 내 경험/언어로 다듬으세요.

**Q9. 여러 번 질문해도 되나요?**
A. 네, 대화형으로 계속 개선할 수 있습니다.

**Q10. 프롬프트 업데이트가 있나요?**
A. [커뮤니티 링크]에서 최신 버전 확인 가능합니다.
