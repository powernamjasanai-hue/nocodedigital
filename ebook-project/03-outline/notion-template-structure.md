## 📖 섹션 0: 템플릿 사용법 안내

### 구조
```
Toggle: "📖 이 템플릿 사용법 (클릭하여 펼치기)"

내부 내용:
├─ Callout (💡 파란색): 시작하기 전에
│  └─ Text: Duplicate 버튼으로 복제 후 사용하세요
├─ Heading 3: 1️⃣ 기본 설정
│  └─ Bulleted list:
│     - 페이지 제목 변경
│     - 커버 이미지 교체
│     - 각 섹션의 [대괄호] 내용을 본인 것으로 교체
├─ Heading 3: 2️⃣ 섹션 작성 순서
│  └─ Text: P → A → T → S → B → C 순으로 작성 권장
├─ Heading 3: 3️⃣ 섹션 추가/삭제 방법
│  └─ Text: 맨 아래 "구조 라이브러리"에서 필요한 블록을 복사하여 붙여넣기
├─ Heading 3: 4️⃣ 레이아웃 변경
│  └─ Text: 2열/3열 레이아웃은 드래그로 조정 가능
├─ Callout (⚠️ 주황색): 주의사항
│  └─ Text:
│     - 이미지 + 제목(H1) + 본문 구조는 유지하세요
│     - 모바일에서 반드시 확인하세요
│     - Share to web 전 최종 검토 필수
└─ Divider
```

## 💰 섹션 1: 가격 & 혜택 (Hero)

### 기본 블록 구조
```
Callout (전체 영역, 배경색: Light gray)
├─ Image (Full width)
│  └─ [전자책 커버 이미지 또는 히어로 이미지를 여기에]
├─ Heading 1 (Center align)
│  └─ [전자책 제목]
│  └─ 예: "노션으로 1시간 만에 디지털 제품 판매 시스템 만들기"
├─ Text (Large, Center align)
│  └─ [한 줄 설명]
│  └─ 예: "코딩 없이 오늘 2-3시간이면 판매 시작"
├─ Divider
├─ 2열 레이아웃:
│  ├─ [왼쪽] Text (Large, Strikethrough)
│  │  └─ 정가: [₩79,000]
│  └─ [오른쪽] Heading 1 (Red color)
│     └─ 할인가: [₩49,000] (38% OFF)
└─ Button (Primary, Center)
   └─ 지금 구매하기
   └─ [Latpeed 링크 연결]
```

### 작성 가이드 (Callout - 회색 배경)
```
💡 작성 팁:
- 커버 이미지는 1200x630px 권장 (나노바나나 활용)
- 제목은 15자 이내로 간결하게
- 한 줄 설명은 핵심 베네핏 1가지만
- 할인율은 30% 이상이면 심리적 효과 큼
```

## ❗ 섹션 2: P (Problem) - 문제 제기

### 기본 블록 구조
```
Callout (전체 섹션 감싸기, 배경색: Light red)
├─ Heading 1
│  └─ [이런 고민 있으시죠?]
├─ Image (Center align)
│  └─ [문제 상황을 표현하는 이미지]
├─ Text (Large)
│  └─ [타겟 고객의 대표적인 문제를 질문형으로]
│  └─ 예: "전자책 PDF는 완성했는데, 크몽 수수료 20%가 아까워서 망설이고 계신가요?"
└─ Bulleted list (또는 3개 Callout을 나열형으로)
   ├─ [문제 1: 구체적 숫자 포함]
   ├─ [문제 2: 구체적 상황 묘사]
   └─ [문제 3: 감정적 표현]
```

### 레이아웃 옵션 (선택 가능)
```
옵션 A: 나열형 (기본)
├─ Callout 1: [문제 1]
├─ Callout 2: [문제 2]
└─ Callout 3: [문제 3]

옵션 B: 2열 비교형
├─ [왼쪽] 현재 상황
└─ [오른쪽] 원하는 상황
```

### 작성 가이드
```
💡 작성 팁:
- 질문형으로 시작하여 독자의 관심 유도
- 3-5개 문제를 구체적 숫자와 함께 나열
- "아깝다", "답답하다", "막막하다" 같은 감정 단어 사용
- 가장 아픈 포인트를 Bold 처리

📊 왜 이 구조인가?
연구에 따르면 사람들은 단일 문제보다 여러 문제가 나열될 때
'이 사람이 나를 이해한다'고 느끼는 확률이 3배 높습니다.
```

## 😰 섹션 3: A (Agitate) - 공감 유발

### 기본 블록 구조
```
Callout (전체 섹션 감싸기, 배경색: Light yellow)
├─ Heading 1
│  └─ [저도 그랬어요]
├─ Quote (또는 Image 선택)
│  └─ [본인의 경험담 또는 공감 이미지]
├─ Text (Large)
│  └─ [본인이 겪었던 구체적 상황]
│  └─ 예: "맞아요. 저도 그랬어요. 100만원 매출에서 20만원이 수수료로 날아가는 걸 보면서..."
└─ Text (계속)
   └─ [감정적 표현 + 구체적 손실]
   └─ 예: "게다가 고객 이메일도 플랫폼이 가져가니까, 내 고객인데도 다시 연락할 방법이 없더라고요."
```

### 작성 가이드
```
💡 작성 팁:
- 본인의 실제 경험 사용 (가장 강력함)
- "답답하다", "속상하다", "억울하다" 같은 감정 단어
- 3-4문장으로 짧게
- 구체적 금액이나 숫자 포함

📊 왜 이 구조인가?
심리학의 '자기 참조 효과'에 따르면, 타인의 경험담이
자신의 것과 유사하다고 느낄 때 신뢰도가 89% 상승합니다.
```

## 🏆 섹션 4: T (Trust) - 가치 입증

### 기본 블록 구조
```
Callout (전체 섹션 감싸기, 배경색: Light blue)
├─ Heading 1
│  └─ [실제 데이터를 보여드릴게요]
├─ Image 또는 Table
│  └─ [비교 데이터 시각화]
│  └─ 옵션 A: 2열 비교 이미지 (Before vs After)
│  └─ 옵션 B: 표 형식 비교
├─ Text (Large, Bold numbers)
│  └─ [구체적 수치 비교]
│  └─ 예: "크몽에서 월 200만원 팔면 40만원을 수수료로 냅니다. 1년이면 480만원이에요."
├─ Divider
├─ Heading 2
│  └─ [저자 소개 / 실적 증명]
├─ 2열 레이아웃:
│  ├─ [왼쪽] Image
│  │  └─ [저자 프로필 또는 실적 스크린샷]
│  └─ [오른쪽] Text
│     └─ [저자 경력 + 구체적 실적]
│     └─ 예: "5년간 상세페이지 디자이너로 일하며 누적 매출 1.4억원 달성"
└─ Bulleted list
   └─ [주요 실적 3-5개]
```

### 레이아웃 옵션
```
옵션 A: 비교형 (2열)
├─ [왼쪽] Before (기존 방법)
└─ [오른쪽] After (제안 방법)

옵션 B: 표 형식
| 항목 | 크몽/탈잉 | Latpeed | 차이 |
|------|----------|---------|------|
| 수수료 | 20% | 1.6% | 18.4% ↓ |
```

### 작성 가이드
```
💡 작성 팁:
- 구체적 숫자로 비교 (%, 금액, 시간)
- 본인 데이터 > 타인 사례 > 일반 통계 순으로 신뢰도 높음
- 저자 소개에는 실적 위주로 (이론X, 경험O)
- Bold 처리로 숫자 강조

📊 왜 이 구조인가?
Nielsen Norman Group 연구에 따르면, 비교 데이터는
단일 주장보다 설득력이 4.3배 높습니다.
```

## 💡 섹션 5: S (Solution) - 솔루션 제시

### 기본 블록 구조
```
Callout (전체 섹션 감싸기, 배경색: Light green)
├─ Heading 1
│  └─ [그래서 이 전자책을 만들었어요]
├─ Text (Large)
│  └─ [솔루션 개요 + 핵심 베네핏]
│  └─ 예: "노션으로 랜딩페이지를 만들고, Latpeed로 결제 받는 방법. 코딩 몰라도, 홈페이지 외주 안 맡겨도, 오늘 2-3시간이면 판매 시작할 수 있어요."
├─ Divider
├─ Heading 2
│  └─ [3단계 프로세스]
└─ 3열 레이아웃 (Callout 3개)
   ├─ [STEP 1]
   │  ├─ 아이콘 (⓵ 또는 이미지)
   │  ├─ 제목: [1단계 이름]
   │  └─ 설명: [간단한 설명 + 소요시간]
   ├─ [STEP 2]
   │  ├─ 아이콘 (⓶)
   │  ├─ 제목: [2단계 이름]
   │  └─ 설명: [간단한 설명 + 소요시간]
   └─ [STEP 3]
      ├─ 아이콘 (⓷)
      ├─ 제목: [3단계 이름]
      └─ 설명: [간단한 설명 + 소요시간]
```

### 작성 가이드
```
💡 작성 팁:
- 3단계로 단순화 (5단계 이상은 복잡해 보임)
- 각 단계마다 소요 시간 명시
- "코딩 몰라도", "초보자도" 같은 장벽 제거 문구
- 전체 소요 시간 합산하여 강조

📊 왜 이 구조인가?
인지 심리학의 '청킹(Chunking)' 원리에 따르면,
정보를 3개 단위로 묶으면 기억률이 65% 향상됩니다.
```

## ✨ 섹션 6: B (Benefit) - 베네핏

### 기본 블록 구조
```
Callout (전체 섹션 감싸기, 배경색: Light purple)
├─ Heading 1
│  └─ [이걸 얻을 수 있어요]
├─ Image (선택)
│  └─ [베네핏 시각화 이미지]
└─ 베네핏 블록 × 3개 이상 (복사 가능)

[베네핏 블록 1]
├─ Callout (아이콘 + 제목)
│  ├─ 아이콘: ⏰ 또는 이미지
│  └─ Heading 2: [베네핏 1 제목]
│     └─ 예: "오늘 2-3시간 만에 판매 시스템 완성"
└─ Text
   └─ [구체적 설명 + 비교]
   └─ 예: "홈페이지 외주 맡기면 2주 걸리고 100만원 듭니다. 노션은 오늘 끝나요."

[베네핏 블록 2] (동일 구조 복사)
├─ Callout
│  ├─ 아이콘: 💰
│  └─ Heading 2: [베네핏 2 제목]
└─ Text

[베네핏 블록 3] (동일 구조 복사)
├─ Callout
│  ├─ 아이콘: ✅
│  └─ Heading 2: [베네핏 3 제목]
└─ Text
```

### 레이아웃 옵션
```
옵션 A: 세로 나열형 (기본)
- 베네핏 1
- 베네핏 2
- 베네핏 3

옵션 B: 2열 레이아웃
├─ [왼쪽] 베네핏 1, 3
└─ [오른쪽] 베네핏 2, (4)
```

### 작성 가이드
```
💡 작성 팁:
- 3가지 베네핏 구조: 시간 / 비용 / 자유
- 각 베네핏마다 구체적 숫자 포함
- Before vs After 비교 형식
- 필요시 베네핏 블록을 복사하여 4-5개로 확장 가능

📊 왜 이 구조인가?
마케팅 연구에 따르면, 3개의 베네핏이 1개보다 전환율이 2.7배,
5개보다는 신뢰도가 1.4배 높습니다. (최적: 3개)
```

## 🚀 섹션 7: C (CTA) - 행동 유도

### 기본 블록 구조
```
Callout (전체 섹션 감싸기, 배경색: Yellow highlight)
├─ Heading 1 (Center align)
│  └─ [지금 시작하세요]
├─ Text (Large, Center)
│  └─ [긴급성 + 행동 유도]
│  └─ 예: "오늘 2-3시간 투자하면 이번 주 안에 첫 판매를 달성할 수 있어요."
├─ Text (계속)
│  └─ [두려움 제거]
│  └─ 예: "완벽하지 않아도 괜찮습니다. 80% 완성도로 시작하고 고객 피드백 받으면서 개선하세요."
├─ Button (Large, Primary, Center)
│  └─ 지금 구매하기 - ₩[가격]
│  └─ [Latpeed 링크]
├─ Divider
└─ Callout (Green background, 리스크 제거)
   ├─ Heading 3: 💚 14일 환불 보장
   └─ Text:
      └─ "구매 후 14일 이내 환불 요청 시 100% 환불해드립니다."
      └─ "이유를 묻지 않습니다. 리스크 제로입니다."
```

### 작성 가이드
```
💡 작성 팁:
- 명확한 행동 지시 ("지금", "아래 버튼")
- 긴급성 문구 ("오늘", "이번 주")
- 리스크 제거 ("환불 보장", "무료 시도")
- 버튼 텍스트에 가격 명시

📊 왜 이 구조인가?
CRO(전환율 최적화) 연구에 따르면, 환불 보장 문구가 있을 때
구매 전환율이 평균 32% 상승합니다.
```

## 🔧 템플릿 제공 방식

### 최종 결정: 개인 페이지 공유

**방법 1: 공개 템플릿 + Duplicate 버튼**
- 장점: 사용자가 쉽게 복제 가능
- 단점: 누구나 접근 가능 (전자책 구매자 구분 불가)
- 추천도: ⭐⭐⭐

**방법 2: 링크 공유 + Allow duplicate**
- 장점: 전자책 구매자에게만 링크 제공 가능
- 단점: 링크 유출 시 통제 어려움
- 추천도: ⭐⭐⭐⭐

**방법 3: 노션 페이지 Export → 구매자에게 Import 파일 전달**
- 장점: 완전한 통제 가능
- 단점: 사용자가 Import 과정 필요 (번거로움)
- 추천도: ⭐⭐

**최종 선택: 방법 2**
- 노션 페이지를 "Can duplicate" 권한으로 설정
- 전자책 구매자에게 Latpeed 자동 발송으로 링크 전달
- 링크는 전자책 부록에도 포함
