## 📝 압축 예시

### Before (800자):
```
## 소목차 1-1-1: 크몽 수수료의 진실

문단 1 (Attention, 200자):
"크몽에 올리면 알아서 팔리겠지?"
저도 그렇게 생각했습니다.

그런데 첫 달 정산 금액을 보고 깜짝 놀랐어요.
100만원 팔았는데 통장에 80만원이 들어왔더라고요.

문단 2 (Insight, 300자):
수수료 계산해보니:
- 판매 금액: 1,000,000원
- 크몽 수수료 20%: -200,000원
- 부가세: -20,000원
- 실제 수령액: 780,000원
...
```

### After (450자):
```
## 1-1: 플랫폼 수수료 비교

크몽 수수료 20%, Latpeed 1.6%
100만원 팔면 18.4만원 차이예요.

| 플랫폼 | 수수료 | 연 1,200만원 판매 시 |
|--------|--------|---------------------|
| 크몽 | 20% | 240만원 손실 |
| 탈잉 | 20% | 240만원 손실 |
| Latpeed | 1.6% | 19만원만 |
| **차이** | - | **221만원 절약** 🔥 |

추가 손해:
- 고객 데이터: 플랫폼이 가져감
- 가격 통제: 자유롭게 못 바꿈
- 브랜드: 플랫폼에 희석

→ Latpeed로 자체 판매하세요.
```

**감소: 800자 → 450자 (44% 압축)** ✅
