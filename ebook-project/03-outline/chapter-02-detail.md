## Section 2-2: 랜딩페이지 기획 - PATSBC 구조 (6페이지)

### 소목차 2-2-1: PATSBC란? (800자)
- 증명된 카피라이팅 공식
- 왜 이 순서인가
- 6가지 요소 한눈에 보기

```
P (Problem)      → 문제 제기: "이런 고민 있으시죠?"
A (Agitate)      → 공감 유발: "정말 답답하죠..."
T (Testimony)    → 근거 제시: "실제로 이런 데이터가..."
S (Solution)     → 솔루션 제시: "그래서 이 전자책을 만들었어요"
B (Benefit)      → 베네핏 3가지: "이걸 얻을 수 있어요"
C (Call-to-Action) → 구매 유도: "지금 시작하세요"
```

### 소목차 2-2-2: P (Problem) - 문제 제기 작성법 (700자)
**작성 원칙:**
- 타겟이 "어? 나 얘기네" 하게 만들기
- 구체적인 상황 묘사
- 질문형으로 시작

**예시 3개:**
```
❌ 나쁜 예: "디지털 제품 판매가 어려우신가요?"
✅ 좋은 예: "전자책 PDF는 완성했는데, 크몽 수수료 20%가 아까워서 망설이고 계신가요?"

❌ 나쁜 예: "마케팅이 고민이신가요?"
✅ 좋은 예: "인스타 팔로워 5,000명인데도 제품 판매는 0원... 뭐가 문제일까요?"
```

### 소목차 2-2-3: A (Agitate) - 공감 유발 작성법 (700자)
**작성 원칙:**
- 문제의 고통 증폭
- "당신만 그런 게 아니에요" 공감
- 감정적 언어 사용

**예시 3개:**
```
"맞아요. 저도 그랬어요.
100만원 매출에서 20만원이 수수료로 날아가는 걸 보면서
'내 노력인데 왜 이렇게 많이 떼가지?' 생각했죠.

게다가 고객 이메일도 플랫폼이 가져가니까,
내 고객인데도 다시 연락할 방법이 없더라고요."
```

### 소목차 2-2-4: T (Testimony) - 근거 제시 작성법 (700자)
**작성 원칙:**
- 데이터, 통계, 사례
- 신뢰도 구축
- "이 방법이 효과 있어요" 증명

**예시 3개:**
```
"실제로 크몽 판매자 A씨는
월 200만원 매출에서 40만원을 수수료로 냈어요.
1년이면 480만원입니다.

반면 자체 판매 시스템(Latpeed)은
수수료가 1.6%라서 200만원 매출에 3.2만원만 냅니다.
연간 38.4만원 vs 480만원 = 441.6만원 절약"
```

### 소목차 2-2-5: S (Solution) - 솔루션 제시 작성법 (700자)
**작성 원칙:**
- 드디어 전자책 등장!
- 어떻게 문제를 해결하는지
- 왜 이 방법이 특별한지

**예시 2개:**
```
"그래서 제가 이 전자책을 만들었어요.

노션으로 랜딩페이지를 만들고,
Latpeed로 결제 받는 방법.

코딩 몰라도, 홈페이지 외주 안 맡겨도,
오늘 2-3시간이면 판매 시작할 수 있어요."
```

### 소목차 2-2-6: B (Benefit) - 베네핏 3가지 작성법 (700자)
**작성 원칙:**
- 기능이 아닌 결과
- 구체적인 숫자
- "당신은 이렇게 달라집니다"

**예시 템플릿:**
```
이 전자책으로 얻을 수 있는 것:

✅ 베네핏 1: 시간
"2-3시간 만에 판매 시스템 완성 (외주 맡기면 2주+100만원)"

✅ 베네핏 2: 비용
"수수료 20% → 1.6% (100만원 팔면 18만원 절약)"

✅ 베네핏 3: 자유
"나만의 판매 채널 (고객 데이터 100% 내 것)"
```

### 소목차 2-2-7: C (Call-to-Action) - 구매 유도 작성법 (700자)
**작성 원칙:**
- 명확한 행동 유도
- 긴급성 (지금 해야 하는 이유)
- 리스크 제거 (환불 보장)

**예시 3개:**
```
❌ 약한 CTA: "관심 있으시면 구매하세요"
✅ 강한 CTA: "지금 시작하면 오늘 안에 판매 시스템 완성됩니다"

✅ 긴급성: "얼리버드 50% 할인은 선착순 100명 (남은 자리 37개)"

✅ 리스크 제거: "14일 환불 보장. 따라했는데 안 되면 100% 환불해드려요."
```

## Section 2-3: ChatGPT로 PATSBC 카피 생성하기 (3페이지)

### 소목차 2-3-1: 통합 프롬프트 (800자)
```
📝 프롬프트 3: PATSBC 카피라이팅 생성

당신은 전문 카피라이터입니다.

【제품 정보】
- 제품명: [내 전자책 제목]
- 타겟: [Section 2-1에서 정의한 타겟]
- 핵심 Pain Point: [Section 2-1에서 발굴한 고민]

【요청】
PATSBC 구조로 랜딩페이지 카피를 작성해주세요.

P (Problem): 타겟의 문제를 질문형으로 2-3문장
A (Agitate): 문제의 고통을 공감하며 3-4문장
T (Testimony): 데이터/통계로 근거 제시 2-3문장
S (Solution): 이 전자책이 어떻게 해결하는지 3-4문장
B (Benefit): 구체적 베네핏 3가지 (각 1-2문장)
C (CTA): 구매 유도 2문장 + 긴급성 1문장

톤: 친근하고 구체적으로 (~요 체)
```
