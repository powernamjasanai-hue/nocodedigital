# Chapter 3: 나노바나나 이미지 제작 - 상세 구조

## Section 3-2: 나노바나나로 이미지 제작 (30분)

**목표:** 3가지 유형의 이미지를 체계적으로 제작

---

## 3-2-1. 전자책 커버 이미지 (10분)

### 소목차: 왜 커버 이미지가 중요한가? (600자)
- 첫인상 = 클릭률 결정
- 전문성 전달
- 신뢰도 구축

### 소목차: 나노바나나로 커버 만들기 (800자)

**STEP 1:** 나노바나나 접속 & 템플릿 선택
- 템플릿 갤러리 → "Book Cover" 검색
- 추천 템플릿 3종

**STEP 2:** 텍스트 삽입
- 전자책 제목 (큰 글씨)
- 서브 타이틀 (작은 글씨)
- 저자명

**STEP 3:** 색상 & 폰트 조정
- 브랜드 컬러 적용
- 가독성 높은 폰트 선택 (고딕체 추천)

**STEP 4:** 다운로드
- 크기: 1200 x 630px (소셜 미디어 최적화)
- 형식: PNG

**완성 예시 이미지**

## 3-2-2. 상황 이미지 (10분)

### 소목차: 상황 이미지란? (600자)
- 타겟의 문제 상황 시각화
- Before/After 비교
- 감정 자극

### 소목차: 3가지 유형의 상황 이미지 (800자)

**유형 1: 문제 상황 이미지**
```
예시:
- 좌절한 표정의 일러스트
- "수수료 20% 날아감" 텍스트
- 빨간색 계열 (위기감)
```

**STEP:**
1. 템플릿: "Problem Illustration"
2. 일러스트 선택 (좌절, 고민 표정)
3. 텍스트: 문제 상황 한 줄
4. 색상: 빨강/주황 (경고색)

**유형 2: Before/After 이미지**
```
예시:
왼쪽 (Before): "플랫폼 수수료 20%"
오른쪽 (After): "Latpeed 수수료 1.6%"
가운데: 화살표 "→"
```

**STEP:**
1. 템플릿: "Comparison"
2. 2칸 나눈 레이아웃
3. Before 텍스트 (어두운 색)
4. After 텍스트 (밝은 색)

**유형 3: 성공 상황 이미지**
```
예시:
- 환하게 웃는 일러스트
- "첫 판매 성공!" 텍스트
- 초록색 계열 (성공감)
```

**완성 예시 이미지 3종**

## 3-2-3. 설명 오브젝트 이미지 (10분)

### 소목차: 설명 오브젝트란? (600자)
- 복잡한 개념을 아이콘+텍스트로 단순화
- 베네핏 시각화
- 가독성 UP

### 소목차: 3가지 오브젝트 제작 (800자)

**오브젝트 1: 베네핏 아이콘 박스 (3개)**
```
구조:
[아이콘]
베네핏 제목
설명 1줄

예시:
[시계 아이콘]
2-3시간 완성
외주 맡기면 2주
```

**STEP:**
1. 템플릿: "Icon + Text Box"
2. 아이콘 3개 선택 (시계, 돈, 자유)
3. 베네핏 제목 입력
4. 설명 1줄 추가
5. 3개 나란히 배치

**오브젝트 2: 가격 표시 박스**
```
구조:
정가: ₩49,000 (취소선)
할인가: ₩29,000 (크게)
할인율: 41% OFF (빨간 라벨)
```

**STEP:**
1. 템플릿: "Pricing Box"
2. 정가 입력 + 취소선
3. 할인가 크게 강조
4. 할인율 라벨 추가 (빨강)

**오브젝트 3: 프로세스 스텝 이미지**
```
구조:
[STEP 1] → [STEP 2] → [STEP 3]
템플릿 복제   카피 작성    결제 연동
5분          30분        30분
```

**STEP:**
1. 템플릿: "Process Flow"
2. 3단계 레이아웃
3. 각 스텝 제목 + 소요 시간
4. 화살표로 연결

**완성 예시 이미지 3종**

## 💡 나노바나나 팁

### 소목차: 실수하기 쉬운 3가지 (600자)
1. **텍스트 너무 많이** → 1개 이미지에 1개 메시지만
2. **색상 너무 화려** → 2-3가지 색상으로 제한
3. **이미지 용량 큼** → 다운로드 후 TinyPNG로 압축

### 소목차: 빠르게 만드는 꿀팁 (600자)
- 템플릿 저장해두기
- 브랜드 컬러 미리 정하기 (Hex 코드)
- 같은 폰트 일관되게 사용
