## PATSBC 랜딩페이지 카피 생성 프롬프트

이 프롬프트는 여러분의 제품 정보를 입력하면 헤드카피, 본문, 시각자료를 자동으로 생성해줍니다.

ChatGPT에 아래 프롬프트를 복사해서 붙여넣고, 각 항목에 맞춰 정보를 입력하세요.

---

### 프롬프트 전문

```
당신은 전환율 높은 랜딩페이지 카피라이터입니다.
PATSBC 프레임워크를 사용해서 디지털 제품 판매 랜딩페이지 카피를 작성해주세요.

# 인풋 데이터

**제품 정보:**
- 제품명: [제품명을 입력하세요]
- 제품 유형: [예: 전자책, 템플릿, 강의, 도구 등]
- 가격: [판매 가격]
- 한 줄 설명: [제품을 한 문장으로 설명]

**타겟 고객:**

- 타겟이 가진 주요 문제: [예: 크몽 수수료 부담, 시간 부족, 방법 모름 등]
- 타겟의 절실한 욕구: [예: 하루 만에 판매 시작, 수수료 절약, 자동화 등]

**경쟁 제품 대비 차별점:**
- 기존 방법의 문제점: [예: 크몽 20% 수수료, 홈페이지 외주 수백만원, 3개월 소요 등]
- 우리 제품의 해결책: [예: 수수료 1.6%, 1시간 세팅, 무료 도구 사용 등]

**실제 증거 (있으면 입력):**

- 사용자 후기: [실제 후기 1-2개]
- 구체적 수치: [예: 전환율 15%, 후기 30개, 누적 판매 100개 등]

**베네핏:**
- 이 제품을 사면 얻는 결과 3가지:
  1. [베네핏 1]

  3. [베네핏 3]

# 출력 형식

## 섹션 1: 헤드카피

타겟 고객의 고통을 3초 안에 후킹하는 헤드카피를 3개 만들어주세요.

**조건:**
- 15자 이내
- 타겟의 절실한 욕구 반영
- 구체적 수치 포함
- 질문형 또는 역설형

**예시:**
- "크몽 수수료 20%, 아깝다고요?"
- "1시간 만에 판매 시작"
- "수수료 1.6%로 낮추는 법"

---

## 섹션 2: 본문 (PATSBC 구조)

### P (Problem - 문제)
타겟 고객이 겪는 문제를 구체적으로 서술해주세요. (200-300자)

**포함 요소:**
- 타겟이 현재 겪는 고통
- 구체적 상황 묘사
- 공감 가는 표현

### A (Agitate - 고통 자극)
문제를 방치하면 어떻게 되는지 자극해주세요. (150-200자)

**포함 요소:**
- "이대로 가면..." 시나리오
- 손실 강조
- 시간/돈/기회 낭비

### T (Testimony - 증거)
실제 증거로 신뢰를 만들어주세요. (150-200자)

**포함 요소:**
- 실제 매출 데이터
- 사용자 후기 (있으면)
- 구체적 수치

### S (Solution - 해결책)
우리 제품이 어떻게 문제를 해결하는지 설명해주세요. (200-300자)

**포함 요소:**
- 3단계 이내 간단한 프로세스
- 소요 시간 명시
- 기술적 장벽 제거 (코딩 불필요 등)

### B (Benefit - 베네핏)
고객이 얻는 구체적 결과를 나열해주세요. (150-200자)

**포함 요소:**
- 3가지 핵심 베네핏
- Before vs After
- 구체적 수치

### C (CTA - 행동 유도)
지금 바로 구매하게 만드는 CTA를 작성해주세요. (50-100자)

**포함 요소:**
- 명확한 행동 지시
- 긴급성 (시간 제한, 수량 제한 등)
- 리스크 제거 (환불 보장 등)

## 섹션 3: 시각자료 제안

랜딩페이지에 들어갈 시각자료를 제안해주세요.

### 1. 커버 이미지
- 이미지 주제: [예: 노트북으로 일하는 프리랜서]
- 분위기: [예: 밝고 깔끔한, 전문적인, 친근한 등]
- 포함할 텍스트: [헤드카피]
- Nanobanana 프롬프트: [AI 이미지 생성 프롬프트 제안]

### 2. 비교 이미지 (Before vs After)
- 비교 항목:
  * Before (기존 방법): [예: 크몽 20% 수수료, 3개월 소요, 수백만원 비용]
  * After (우리 제품): [예: Latpeed 1.6%, 1시간 세팅, 무료]
- 시각화 방식: [예: 표, 인포그래픽, 2단 비교 등]

### 3. 프로세스 이미지
- 단계별 아이콘:
  1. [1단계 설명] - 아이콘: [예: 문서 아이콘]
  2. [2단계 설명] - 아이콘: [예: 설정 아이콘]
  3. [3단계 설명] - 아이콘: [예: 체크 아이콘]
- 시각화 방식: [예: 타임라인, 화살표 흐름도 등]

### 4. 베네핏 일러스트
- 베네핏별 시각자료:
  * [베네핏 1] → [시각화 아이디어]
  * [베네핏 2] → [시각화 아이디어]
  * [베네핏 3] → [시각화 아이디어]

### 5. 증거 자료
- [매출 그래프 / 후기 스크린샷 / 수치 인포그래픽 중 제안]
- 강조할 수치: [구체적 숫자]
```

### 사용 방법

1. ChatGPT(https://chat.openai.com)에 접속하세요. 무료 계정으로도 충분합니다
2. 위 프롬프트를 전체 복사해서 붙여넣으세요
3. [대괄호] 안의 내용을 여러분의 실제 데이터로 교체하세요. 예를 들어 [제품명을 입력하세요] 부분에 "노션으로 1시간 만에 디지털 제품 판매 시스템 만들기"처럼 실제 제품명을 넣는 거예요
4. 엔터를 누르면 ChatGPT가 10-30초 안에 자동으로 헤드카피, 본문, 시각자료를 생성해줍니다

**팁:**
- 실제 데이터를 최대한 구체적으로 입력할수록 결과가 좋아요. 예를 들어 "수수료가 아까워요"보다는 "15만원 매출에 3만원 수수료가 아까워요"처럼 숫자를 넣으면 훨씬 구체적인 카피가 나옵니다
- 매출 데이터가 없으면 "아직 없음"이라고 입력하세요. ChatGPT가 그에 맞춰서 다른 증거(통계, 사례 등)를 제안해줄 거예요
- 생성된 결과를 그대로 쓰지 말고, 여러분의 톤앤매너에 맞게 수정하세요. ChatGPT는 초안을 만들어주는 도구일 뿐이에요. 80%는 쓰되 20%는 여러분의 경험과 언어로 다듬어야 진짜 여러분의 목소리가 됩니다

### 실제 활용 예시

**인풋:**
```
제품명: 노션 프리랜서 가이드
제품 유형: 전자책
가격: 9,900원
한 줄 설명: 프리랜서가 계약서 없이 일해서 손해보지 않는 법

타겟 고객: 프리랜서 초보 (디자이너, 개발자, 작가 등)
주요 문제: 범위 없는 계약으로 무한 수정 요청 받음
절실한 욕구: 정당한 금액 받고 일하기

기존 방법 문제: 계약서 양식 10만원, 법률 검토 30만원
우리 제품 해결책: 9,900원 전자책에 계약서 템플릿 포함

실제 증거: 3일 만에 50만원 매출, 구매자 50명 중 30명 후기
베네핏:
1. 시간당 5천원 → 3만원으로 수익 증가
2. 무한 수정 요청 차단
3. 계약서 템플릿 바로 사용 가능
```

**아웃풋 (ChatGPT 생성 결과):**

**헤드카피:**
1. "시간당 5천원? 프리랜서 아니에요"
2. "30만원 계약에 60시간 일했다면"
3. "무한수정 요청, 이제 그만"

**본문 (P - Problem):**
"프리랜서로 일하면서 이런 경험 있으세요? 30만원 계약했는데, 한 달 내내 수정 요청이 들어와요. '여기 좀 바꿔줘', '이것도 추가해줘'. 처음엔 10시간이면 끝날 줄 알았는데, 60시간 넘게 일했습니다. 계산해보니 시간당 5천원. 편의점 알바보다 못한 금액이에요."

(이하 A, T, S, B, C 섹션 생성...)

**시각자료:**
1. 커버 이미지: 노트북 앞에서 좌절한 프리랜서 + "시간당 5천원? 프리랜서 아니에요" 텍스트
2. 비교 이미지:
   - Before: 30만원 계약 → 60시간 작업 → 시간당 5천원
   - After: 범위 명시 계약 → 10시간 작업 → 시간당 3만원
3. 프로세스: 계약서 다운로드 → 정보 입력 → 고객 전송 (3단계)
