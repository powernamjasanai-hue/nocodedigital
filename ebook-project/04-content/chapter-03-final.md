# Chapter 3: 노션 랜딩페이지 제작 & 공개

## 3-1: 노션 템플릿 복제하기

이제 실제로 만들 차례예요.
Chapter 2에서 전략과 카피를 다 만들었으니까 이제는 노션에 옮기면 됩니다.

처음부터 빈 페이지에 만들면 막막해요.
템플릿을 쓰세요.

notion.so에 로그인하세요.
왼쪽 사이드바에서 '+ 새 페이지' 버튼을 누르세요.
'템플릿' 탭을 클릭하세요.

검색창에 'landing page'를 입력하면 템플릿이 나와요.
추천하는 건 'Product Landing Page' 템플릿입니다.
클릭해서 '복제' 버튼을 누르세요.

5초 만에 내 워크스페이스에 템플릿이 복사됩니다.

페이지 제목을 바꾸세요.
'내 전자책 제목 - 랜딩페이지'로 바꾸면 돼요.

템플릿에 기본 섹션이 있어요.
Hero / Features / Testimonials / FAQ / CTA
이런 식이에요.

우리는 PATSBC 구조로 바꿀 거예요.
기존 섹션을 다 지우세요.
'/' 슬래시를 누르고 'heading 1'을 선택해서 새 섹션을 만드세요.

6개 섹션을 만드세요.

섹션 1: Problem (문제 제기)
섹션 2: Agitate (공감 유발)
섹션 3: Testimony (근거 제시)
섹션 4: Solution (솔루션)
섹션 5: Benefit (베네핏)
섹션 6: Call-to-Action (구매 유도)

이제 골격이 완성됐어요.
여기에 카피를 붙여넣으면 됩니다.

## 3-2: PATSBC 카피 붙여넣기

Chapter 2에서 ChatGPT로 만든 카피를 꺼내세요.
이제 각 섹션에 붙여넣을 거예요.

**섹션 1: Problem**

Heading 1으로 '이런 고민 있으시죠?'를 쓰세요.
그 아래 본문에 ChatGPT가 만든 Problem 카피를 붙여넣으세요.

예시:
'전자책 PDF는 완성했는데, 크몽 수수료 20%가 아까워서 망설이고 계신가요?
홈페이지 외주 맡기려니 100만원이고, 혼자 만들려니 방법을 모르겠고...
내가 마케팅한 고객인데 플랫폼이 이메일을 가져가니까 재구매 유도도 못 하고요.'

글자 크기를 키우세요.
드래그해서 'Large'를 선택하면 됩니다.
굵게도 만드세요.

---

**섹션 2: Agitate**

Heading 1으로 '저도 그랬어요'를 쓰세요.
Agitate 카피를 붙여넣으세요.

예시:
'맞아요. 저도 그랬어요.
100만원 매출에서 20만원이 수수료로 날아가는 걸 보면서 '내 노력인데 왜 이렇게 많이 떼가지?' 생각했죠.

게다가 고객 이메일도 플랫폼이 가져가니까, 내 고객인데도 다시 연락할 방법이 없더라고요.'

이 섹션은 본인 경험이 들어가야 해요.
ChatGPT 답변의 80%는 쓰되, 20%는 본인 언어로 다듬으세요.

---

**섹션 3: Testimony**

Heading 1으로 '실제 데이터를 보여드릴게요'를 쓰세요.
Testimony 카피를 붙여넣으세요.

예시:
'크몽에서 월 200만원 팔면 40만원을 수수료로 냅니다. 1년이면 480만원이에요.
Latpeed는 1.6%라서 200만원 매출에 3.2만원만 냅니다. 연간 38.4만원이에요.
차이가 441.6만원입니다.'

숫자를 굵게 표시하세요.
드래그해서 'Bold' 버튼을 누르면 됩니다.

---

**섹션 4: Solution**

Heading 1으로 '그래서 이 전자책을 만들었어요'를 쓰세요.
Solution 카피를 붙여넣으세요.

예시:
'노션으로 랜딩페이지를 만들고, Latpeed로 결제 받는 방법.
코딩 몰라도, 홈페이지 외주 안 맡겨도, 오늘 2-3시간이면 판매 시작할 수 있어요.

이 전자책은 44단계 체크리스트로 구성되어 있어서 따라하기만 하면 됩니다.'

---

**섹션 5: Benefit**

Heading 1으로 '이걸 얻을 수 있어요'를 쓰세요.
Benefit 카피를 붙여넣으세요.

3가지 베네핏을 번호 리스트로 만드세요.
'/' 슬래시를 누르고 'numbered list'를 선택하면 됩니다.

예시:
1. 오늘 2-3시간 만에 판매 시스템 완성 (홈페이지 외주 맡기면 2주 + 100만원)
2. 수수료 20% → 1.6%로 절감 (100만원 팔 때마다 18.4만원 절약)
3. 나만의 판매 채널 확보 (고객 데이터 100% 내 것)

---

**섹션 6: Call-to-Action**

Heading 1으로 '지금 시작하세요'를 쓰세요.
CTA 카피를 붙여넣으세요.

예시:
'오늘 2-3시간 투자하면 이번 주 안에 첫 판매를 달성할 수 있어요.
완벽하지 않아도 괜찮습니다. 80% 완성도로 시작하고 고객 피드백 받으면서 개선하세요.

아래 버튼을 눌러서 지금 시작하세요.'

버튼을 만드세요.
'/' 슬래시를 누르고 'button'을 입력하세요.
버튼 텍스트를 '지금 구매하기 - 49,000원'으로 바꾸세요.

버튼 링크는 나중에 Chapter 4에서 Latpeed 결제 링크로 연결할 거예요.
지금은 비워두세요.

PATSBC 카피 붙여넣기 완료됐어요.
15분 걸렸습니다.

## 3-3: 랜딩페이지 구조 잡기

카피를 다 넣었으면 이제 구조를 다듬어야 해요.
가독성을 높이는 작업입니다.

**여백 추가하기**

섹션과 섹션 사이에 여백을 넣으세요.
빈 줄을 2-3개 추가하면 됩니다.
엔터를 3번 누르세요.

너무 빽빽하면 답답해 보여요.

**구분선 넣기**

섹션 사이에 구분선을 넣으세요.
'/' 슬래시를 누르고 'divider'를 입력하면 선이 생깁니다.

Problem과 Agitate 사이, Testimony와 Solution 사이에 넣으세요.

**색상 블록 활용하기**

중요한 문장은 색상 블록으로 강조하세요.
문장을 드래그하고 '...' 메뉴를 누르세요.
'Color' → 'Background'에서 'Yellow'를 선택하세요.

노란색 배경이 생기면서 눈에 띕니다.

예시:
'100만원 팔 때마다 18.4만원 절약됩니다' ← 이런 문장

**콜아웃 박스 만들기**

중요한 정보는 콜아웃 박스에 넣으세요.
'/' 슬래시를 누르고 'callout'을 입력하세요.

예시:
💡 이 전자책으로 얻을 수 있는 것
- 2-3시간 만에 판매 시스템 완성
- 수수료 20% → 1.6%
- 고객 데이터 100% 확보

아이콘을 바꿀 수 있어요.
콜아웃 왼쪽 아이콘을 클릭해서 다른 걸로 바꾸세요.
💡, ⚡, 🎯, ✅ 이런 거요.

하지만 스타일 가이드에서 이모지 사용 금지라고 했으니까 꼭 필요한 경우만 쓰세요.
아니면 아이콘 없이 텍스트만 써도 됩니다.

**정렬 조정하기**

제목은 가운데 정렬이 좋아요.
Heading 1을 드래그하고 '...' 메뉴를 누르세요.
'Align center'를 선택하세요.

본문은 왼쪽 정렬이 가독성이 좋습니다.

구조 잡기 완료됐어요.
이제 이미지를 만들 차례예요.

## 3-4: 전자책 커버 이미지 만들기

랜딩페이지 맨 위에 전자책 커버 이미지를 넣어야 해요.
첫인상이 클릭률을 결정합니다.

나노바나나를 쓸 거예요.
nanobanana.io에 접속하세요.
무료로 쓸 수 있어요.

로그인하면 템플릿 갤러리가 보여요.
검색창에 'book cover'를 입력하세요.
템플릿 10개 정도 나와요.

심플한 디자인을 고르세요.
너무 화려하면 오히려 신뢰도가 떨어집니다.

템플릿을 클릭하면 편집 화면이 나와요.

**텍스트 수정하기**

기본 텍스트를 내 전자책 제목으로 바꾸세요.
클릭하면 바로 편집됩니다.

예시:
큰 글씨: '노션으로 1시간 만에'
중간 글씨: '디지털 제품 판매 시스템 만들기'
작은 글씨: '저자 이름'

제목이 너무 길면 2줄로 나누세요.
가독성이 중요합니다.

**색상 바꾸기**

배경색과 텍스트 색을 바꿀 수 있어요.
왼쪽 메뉴에서 'Background'를 클릭하세요.
색상 팔레트가 나와요.

브랜드 컬러가 있으면 그걸 쓰세요.
없으면 파란색 계열이 무난해요.
#2E5EAA 이런 코드를 입력하면 됩니다.

텍스트 색은 흰색이나 검은색이 가독성이 좋아요.

**폰트 바꾸기**

텍스트를 선택하고 상단 메뉴에서 'Font'를 클릭하세요.
고딕체를 추천해요.
'Noto Sans KR'이나 'Pretendard'가 깔끔합니다.

**다운로드하기**

오른쪽 상단에 'Download' 버튼이 있어요.
클릭하세요.

크기는 1200 x 630px로 설정하세요.
소셜 미디어 최적화 사이즈예요.
형식은 PNG로 선택하세요.

다운로드 버튼을 누르면 내 컴퓨터에 저장됩니다.

파일명을 'ebook-cover.png'로 바꾸세요.

이제 노션 랜딩페이지 맨 위에 이 이미지를 넣으세요.
'/' 슬래시를 누르고 'image'를 입력하세요.
'Upload' 버튼을 누르고 방금 다운로드한 파일을 선택하세요.

5초 만에 업로드됩니다.

이미지를 클릭하고 'Full width'로 설정하세요.
화면 전체에 꽉 차게 보입니다.

커버 이미지 완성됐어요.
10분 걸렸습니다.

## 3-5: 문제 상황 이미지 만들기

## 3-6: Before/After 비교 이미지 만들기

Testimony 섹션에 넣을 비교 이미지를 만들 거예요.
'플랫폼 vs 자체 판매' 차이를 보여주는 거예요.

나노바나나에서 새 프로젝트를 시작하세요.

템플릿 갤러리에서 'comparison'을 검색하세요.
2칸으로 나뉜 레이아웃을 선택하세요.

**왼쪽 (Before) 작성하기**

작은 글씨로 상단에 배치하세요.

그 아래 문제 상황을 쓰세요.

예시:
'플랫폼 판매'
'수수료 20%'
'고객 데이터 없음'

## 3-8: 베네핏 아이콘 박스 만들기

Benefit 섹션에 넣을 아이콘 박스를 만들 거예요.
3가지 베네핏을 시각화하는 거예요.

나노바나나에서 새 프로젝트를 시작하세요.

템플릿 갤러리에서 'icon box'를 검색하세요.
3개 박스가 나란히 있는 레이아웃을 선택하세요.
