# Chapter 4: Latpeed 결제 연동

## 4-1: Latpeed 가입하기

노션 랜딩페이지를 만들었으면 이제 결제를 받아야 해요.
Latpeed를 쓸 거예요.

latpeed.com에 접속하세요.
오른쪽 상단에 '회원가입' 버튼이 있어요.
클릭하세요.

전화번호만 입력하면 됩니다.
이메일도 필요 없어요.
인증번호 받고 입력하면 끝이에요.

1분이면 가입 완료됩니다.

로그인하면 대시보드가 보여요.
왼쪽 메뉴에 '상품 관리', '고객 관리', '메시지 관리'가 있습니다.

가입 완료됐어요.

## 4-2: 플랜 선택하기

Latpeed는 3가지 플랜이 있어요.

**Free 플랜**
- 판매 수수료: 1.6%
- 구독료: 무료
- 기능: 제한 없는 상품 등록, PDF 자동 발송, 알림톡 무료 발송

**Lite 플랜**
- 판매 수수료: 4.6%
- 구독료: 무료
- 기능: Free + 고객 관리, 쿠폰, 타임딜

**Pro 플랜**
- 판매 수수료: 1.6%
- 구독료: 월 24,000원 (연 결제 시)
- 기능: Lite + 무제한 컬렉션, 외부 툴 연동, 멤버십

어떤 플랜을 선택해야 할까요?

**초보자는 Free로 시작하세요.**

저도 처음엔 Free로 시작했어요.
무료 자료 제공 페이지를 만들어서 고객 설문을 받아봤습니다.
Latpeed가 어떻게 작동하는지 익숙해졌어요.

실제 판매는 안 하고 '무료 이북 다운로드' 같은 걸로 연습한 거예요.
설문지 만들고, 자동 발송 설정하고, 메시지 자동화 테스트해봤습니다.

이렇게 익숙해진 후에 Pro를 결제했어요.

**언제 Pro로 업그레이드하나요?**

매출을 발생시킬 수 있는 상품이 있을 때 업그레이드하세요.

저는 웨비나를 판매하기 직전에 Pro로 바꿨어요.
웨비나로 3억 매출을 냈습니다.
전자책 판매할 때도 Pro를 썼어요.

Pro의 장점은 명확해요.
수수료가 1.6%로 낮고, 외부 툴 연동이 돼요.
멤버십(정기결제) 기능도 쓸 수 있습니다.

하지만 처음부터 Pro 결제할 필요는 없어요.
Free로 연습하고, 자신감 생기면 Pro로 가세요.

일단 Free 플랜으로 시작하겠습니다.

## 4-3: 제품 유형 선택하기

대시보드에서 '상품 관리' 메뉴를 클릭하세요.
'+ 상품 추가' 버튼을 누르세요.

4가지 유형이 나와요.

**1. 이벤트 상품**
오프라인 모임, 웨비나, 네트워킹 파티 같은 거예요.
날짜와 시간이 정해진 이벤트입니다.

**2. 파일형 디지털 상품**
PDF, 동영상, 템플릿 같은 거예요.
구매하면 파일을 자동으로 발송합니다.

**3. 링크형 디지털 상품**
온라인 강의, 노션 템플릿 같은 거예요.
구매하면 링크를 전달합니다.

**4. 기타 상품**
위 3가지에 해당 안 되는 거예요.
컨설팅, 코칭 같은 서비스입니다.

전자책은 '파일형 디지털 상품'이에요.
클릭하세요.

## 4-4: 기본 정보 입력하기

이제 상품 정보를 입력할 거예요.

**상품 썸네일**

대표 이미지를 업로드하세요.
Chapter 3에서 나노바나나로 만든 전자책 커버 이미지를 쓰면 됩니다.
'ebook-cover.png' 파일을 업로드하세요.

권장 크기는 1200 x 630px예요.

**상품 이름**

전자책 제목을 입력하세요.

예시:
'노션으로 1시간 만에 디지털 제품 판매 시스템 만들기'

명확하게 쓰세요.
SEO에도 영향을 미칩니다.

**판매 일정 설정**

상시 판매할 거면 '판매 기간 제한 없음'을 선택하세요.
얼리버드 할인 같은 걸 하려면 시작일/종료일을 설정하면 됩니다.

저는 상시 판매로 설정했어요.

**상품 가격 설정**

Chapter 2에서 정한 가격을 입력하세요.

예시:
49,000원

할인 가격도 설정할 수 있어요.
정가 79,000원, 할인가 49,000원 이렇게요.

할인율이 자동으로 표시됩니다.
'38% OFF' 이런 식이에요.

심리적 효과가 있어서 전환율이 올라갑니다.

기본 정보 입력 완료됐어요.
'다음' 버튼을 누르세요.

## 4-5: 노션 랜딩페이지 연동하기

이제 랜딩페이지를 연결할 차례예요.

Latpeed는 노션과 완벽하게 연동됩니다.
어렵지 않아요.

**노션 페이지 공유 링크 복사하기**

Chapter 3에서 만든 노션 랜딩페이지를 여세요.
오른쪽 상단 'Share' 버튼을 클릭하세요.
'Share to web'이 켜져 있는지 확인하세요.

'Copy link' 버튼을 눌러서 링크를 복사하세요.

예시:
https://your-workspace.notion.site/Digital-Product-Sales-1a2b3c4d5e6f

**Latpeed에서 불러오기**

Latpeed 상품 등록 페이지로 돌아오세요.
'상품 상세 설명' 섹션이 있어요.

'노션으로 작성 후 불러오기' 버튼이 보여요.
클릭하세요.

팝업이 뜹니다.
노션 링크를 붙여넣으세요.
'불러오기' 버튼을 누르세요.

5초 만에 노션 페이지가 Latpeed에 연동됩니다.
PATSBC 구조, 이미지, 모든 게 그대로 보여요.

미리보기 버튼을 눌러서 확인하세요.
잘 보이나요?

노션 연동 완료됐어요.

## 4-6: 고객 설문지 작성하기

구매할 때 고객 정보를 수집해야 해요.
이메일은 기본이고, 추가 질문도 받을 수 있습니다.

'고객 정보 수집 설문' 섹션으로 가세요.

기본 항목은 이미 체크되어 있어요.
- 이름
- 이메일
- 전화번호

여기에 추가 질문을 넣으세요.

**추가 질문 예시:**

질문 1: 어디서 이 전자책을 알게 되셨나요?
- 인스타그램
- 블로그
- 지인 추천
- 검색

이건 마케팅 채널 분석에 필요해요.
어디서 유입되는지 알아야 광고비를 어디에 쓸지 결정할 수 있습니다.

질문 2: 가장 큰 고민이 무엇인가요?
- 크몽 수수료 아까움
- 홈페이지 만들 줄 몰라서
- 마케팅 방법 모름
- 시간 없음

이건 타겟 분석에 필요해요.
실제 고객이 어떤 고민을 갖고 있는지 데이터로 쌓입니다.
다음 제품 만들 때 참고할 수 있어요.

질문은 3개 이하로 하세요.
너무 많으면 귀찮아서 이탈합니다.

설문지 완성됐어요.

## 4-7: 결제 한도 이해하기

Latpeed는 처음에 결제 한도가 있어요.

**초기 한도: 월 100만원**

처음 가입하면 월 100만원까지만 결제를 받을 수 있습니다.
100만원 넘으면 결제가 막혀요.

'100만원이면 적은 거 아니야?'
네, 맞아요.

하지만 걱정 마세요.
자동으로 늘어납니다.

**심사 후 한도: 월 2,500만원**

거래가 발생하고 시간이 지나면 Latpeed에서 자동으로 심사해요.
이상 거래가 없으면 한도가 자동으로 증가합니다.

저는 처음에 100만원이었는데 2주 후에 500만원으로 늘었어요.
1달 후에는 1,000만원이었고요.
지금은 2,500만원까지 받을 수 있습니다.

웨비나 3억 매출 낼 때는 월 2,500만원 한도였어요.
3개월에 걸쳐서 판매했습니다.

**한도 확인 방법**

대시보드 오른쪽 상단에 '결제 한도' 표시가 있어요.
현재 한도와 사용 금액이 보입니다.

한도가 부족하면 고객센터에 문의하면 돼요.
증빙 자료 제출하면 수동으로도 늘려줍니다.

초기에는 100만원으로 시작하니까 참고하세요.

## 4-8: 후기 유도 콘텐츠 기획하기

상품 등록이 거의 끝났어요.
마지막으로 중요한 게 하나 남았습니다.

**후기 자동화 시스템**이에요.

왜 중요할까요?

통계를 보여드릴게요.

2021년 UGC 전환 영향 분석에 따르면 쇼핑객이 리뷰와 상호작용할 때 전환율이 **120.3% 증가**합니다.
리뷰 11~30개가 있으면 전환율이 **200% 증가**해요.
리뷰 101개 이상이면 **250% 증가**합니다.

소비자의 **78.6%**가 구매 전 항상 리뷰를 확인한다고 해요.
실구매자 후기가 쇼핑몰 추천보다 **10배** 영향력이 높습니다.

후기가 많으면 훨씬 잘 팔려요.

그럼 어떻게 후기를 많이 받을까요?

**베네핏 자료를 제공하세요.**

후기 작성한 사람에게 추가 혜택을 주는 거예요.
단순히 '후기 써주세요'라고 하면 안 써요.
'후기 쓰면 이거 드려요'라고 하면 씁니다.

**베네핏 자료 예시:**

프리랜서 가이드 전자책이라면?
→ 견적서 양식 템플릿 제공

글쓰기 워크시트라면?
→ 글 주제 리서치 ChatGPT 프롬프트집 제공

노션 템플릿이라면?
→ 추가 템플릿 1개 더 제공

디지털 마케팅 가이드라면?
→ SNS 콘텐츠 기획 체크리스트 제공

**베네핏 자료 기획 방법:**

타겟이 원하는 걸 주세요.

Chapter 2에서 ChatGPT로 타겟을 분석했죠?
그때 나온 '절실한 욕구'를 보세요.

예시:
전자책 주제: 노션으로 디지털 제품 판매하기
타겟의 절실한 욕구: 빠르게 실행하는 것

베네핏 자료:
→ '10분 만에 따라 하는 노션 템플릿 체크리스트'
→ '첫 고객 유치를 위한 인스타 DM 템플릿 10종'

이런 식이에요.

**베네핏 자료 만들기:**

거창하게 만들 필요 없어요.
1-2페이지면 충분합니다.

PDF로 만들거나 노션 페이지로 만들면 돼요.
30분이면 만들 수 있습니다.

저는 프리랜서 가이드 전자책 팔 때 '견적서 양식'을 베네핏으로 줬어요.
엑셀 파일 1개였습니다.
30분 만에 만들었어요.

후기 작성률이 60%였어요.
50명 구매했는데 30명이 후기를 남겼습니다.

베네핏 자료를 미리 준비하세요.
다음 섹션에서 이걸 자동화하는 법을 알려드릴게요.

## 4-9: CRM 메시지 자동화 설정하기

이제 마지막 단계예요.
후기를 자동으로 받는 시스템을 만들 거예요.

상품 등록을 완료하세요.
'저장' 버튼을 누르세요.

상품 목록 페이지로 이동합니다.
방금 만든 상품이 보여요.
클릭하세요.

상단 메뉴에 '메시지 관리'가 있어요.
클릭하세요.

4가지 메시지 타입이 나와요.

**1. 결제 완료**
구매 직후에 자동으로 발송되는 메시지예요.

**2. 후기 요청**
구매 후 일정 시간이 지나면 발송되는 메시지예요.

**3. 후기 작성 완료**
후기 작성하면 자동으로 발송되는 메시지예요.

**4. 후기 작성 완료 (베네핏 제공)**
후기 작성한 사람에게 베네핏을 주는 메시지예요.

하나씩 설정할게요.

---

**메시지 1: 결제 완료**

'결제 완료' 메시지를 클릭하세요.
'알림톡 자동 발송' 토글을 켜세요.

기본 템플릿이 있어요.

```
안녕하세요, {{구매자 이름}}님!

{{상품명}} 구매 감사합니다.

PDF 파일이 이메일로 발송되었습니다.
확인 부탁드려요.

문의사항은 이메일로 연락주세요.
```

이걸 조금 수정하세요.

```
안녕하세요, {{구매자 이름}}님!

{{상품명}} 구매 감사합니다.

이메일로 전자책 PDF가 발송되었어요.
확인해주세요.

읽으시면서 도움이 되셨다면 후기를 남겨주시면 감사하겠습니다.
후기 작성하신 분께는 특별 자료를 드려요!

{{특별 자료 이름}}을 드립니다.
```

마지막에 후기 유도를 살짝 넣었어요.
베네핏 자료 이름도 명시했습니다.

저장하세요.

---

**메시지 2: 후기 요청**

'후기 요청' 메시지를 클릭하세요.

발송 시점을 설정할 수 있어요.
'구매 후 3일'로 설정하세요.

3일 지나면 자동으로 후기 요청 메시지가 갑니다.

```
안녕하세요, {{구매자 이름}}님!

{{상품명}} 잘 보고 계신가요?

도움이 되셨다면 후기를 남겨주시면 감사하겠습니다.

후기 작성하신 분께는 {{베네핏 자료 이름}}을 드려요.
프리랜서 일할 때 바로 쓸 수 있는 견적서 양식입니다.

아래 링크에서 후기 작성해주세요:
{{후기 작성 링크}}

감사합니다!
```

베네핏을 명확히 강조했어요.
'이거 받으려면 후기 써야 해'라는 걸 인지시키는 겁니다.

저장하세요.

---

**메시지 3: 후기 작성 완료**

후기를 작성하면 자동으로 발송되는 메시지예요.

```
{{구매자 이름}}님, 후기 작성 감사합니다!

소중한 의견 잘 읽었어요.

약속드린 {{베네핏 자료 이름}}을 첨부합니다.
[파일 첨부 또는 링크]

앞으로도 좋은 콘텐츠로 찾아뵙겠습니다.
감사합니다!
```

여기서 베네핏 자료를 실제로 전달합니다.

PDF 파일을 첨부하거나 노션 링크를 넣으세요.
