## 📊 프로젝트 개요

### 제품명
코딩 없이 노션으로 만드는 1시간 디지털 판매 시스템

### 타겟
전자책 PDF 완성했지만 판매 방법 모르는 사람

### 핵심 베네핏
1. 2-3시간 만에 판매 준비 완료
2. 수수료 20% → 1.6% 절감
3. 나만의 판매 채널 확보

### 차별점
- 1.4억 수익 실전 경험 기반
- 노션 템플릿 + 워크시트 제공
- 1개월 Q&A 지원
