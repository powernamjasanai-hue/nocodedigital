# 디지털 제품 아이디어

이 디렉토리는 디지털 제품 아이디어를 모아두는 공간입니다.

## 구조

각 제품 아이디어는 별도의 마크다운 파일이나 하위 디렉토리로 관리할 수 있습니다.

## 아이디어 템플릿

새로운 제품 아이디어를 추가할 때 다음 형식을 사용하세요:

```markdown
# [제품명]

## 개요
간단한 제품 설명

## 타겟 고객
누구를 위한 제품인가?

## 핵심 기능
- 기능 1
- 기능 2
- 기능 3

## 수익 모델
어떻게 수익을 창출할 것인가?

## 개발 난이도
쉬움 / 보통 / 어려움

## 우선순위
높음 / 보통 / 낮음

## 메모
추가 아이디어나 참고사항
```
